## 1. How to use this document

1. **Every program gets one row** in the right segment table (section 4), with a
   unique ID (e.g. `POL-03`, `EDU-12`). Never reuse an ID.
2. **Keep the Status column current** using the legend below. Confirmed programs
   also go into the [Calendar](#3-calendar-anchors-2026-27).
3. **Look-alike audiences** (section 5) are leads. When one gets a contact person,
   move it into its segment table as a `Lead` row.
4. **After each program**, fill in the outcome in the
   [Post-program log](#8-post-program-log).

### Status legend

| Status | Meaning |
| --- | --- |
| 💡 Idea | Worth doing, no contact yet |
| 🎯 Lead | We know who to approach |
| 📞 In talks | Contact made, they are interested ("they are asking") |
| ✅ Confirmed | Date, venue and audience size agreed |
| 🎤 Done | Program held — fill in the post-program log |
| ⏸ On hold / ❌ Dropped | Write the reason in Notes |

### Priority

- **P1** — high-cadre, high-visibility or very large audience; Prabhu must do it personally.
- **P2** — strong audience; Prabhu ideally, senior devotee as backup.
- **P3** — good to do; can be led by a senior devotee with a recorded or video message from Prabhu.

## 6. Strategies

1. **Ride the Sannyasa moment.** The first 90 days after Sannyasa Diksha carry the
   most interest. Book the highest-cadre programs (police HQ, IAS / IPS, CXO) in
   this window and use "first address after Sannyasa" in invitations.
2. **Top-down unlocks bottom-up.** One senior-officer program (POL-01, POL-02)
   should lead to permission for constables (B) and prisoners (C). Ask for the
   follow-on program at the end of every senior meeting.
3. **One address, many institutions.** Prefer federations and umbrella bodies —
   DGP conferences, principals' associations, RWA federations, industry forums,
   IMA / ICAI chapters.
4. **Festival-anchored exclusives.** Janmashtami, Gita Jayanti and Rathayatra
   give natural reasons to invite CXOs, IAS / IPS officers and professionals to
   exclusive, well-hosted evenings.
5. **Tailor the theme to the audience.**

   | Audience | Talk themes |
   | --- | --- |
   | Police | Stress, anger management, integrity, family life, service attitude |
   | Prisoners | Transformation, second chances, Bhagavad Gita, japa |
   | Startup founders | Purpose, resilience, burnout, ethical leadership |
   | Students | Focus, digital distraction, exam stress, purpose, character |
   | CXOs / civil servants | Spiritual leadership, decision-making, ethics, legacy |
   | Doctors / lawyers / CAs | Compassion, integrity, inner balance |
   | Diaspora | Keeping culture and values alive for the next generation |

6. **Always leave something behind.** Bhagavad Gita copies, japa beads, a QR code
   to join a follow-up course, and a named devotee for follow-up.
7. **Build a follow-up funnel.** Each program feeds a weekly class (prison,
   police, campus, community), then Ashraya, then Diksha.
8. **Content multiplies reach.** Record every address; cut reels and shorts;
   publish on the temple's channels within 48 hours.
9. **International tours ride the convention calendar.** Secure TTA / AKKA / TANA /
   ATA keynote slots 6–9 months ahead, then build city programs and donor meets
   around them.
